# Alcance del repositorio independiente

Este es el repositorio autónomo de GISELA: fuente Python, bibliotecas independientes, contratos, paquetes narrativos de prueba, utilidades, tests y documentación. Para su funcionamiento offline no requiere la novela visual ni el SDK Ren'Py.

Los documentos anteriores a la extracción pueden mencionar `renpy/`, `docs/guides/examples` y otros directorios del antiguo monorrepositorio. Esas rutas no deben interpretarse como dependencias vigentes. Véase el [roadmap](../operatives/ROADMAP.md) para el estado técnico actual.

El software se distribuye conforme a [Apache 2.0](../../LICENSE). Los relatos y contenidos narrativos incluidos se reservan separadamente según la [nota de licencia](../../README.md#license-and-copyright).
