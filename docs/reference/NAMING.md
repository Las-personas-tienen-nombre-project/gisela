# Nombres y responsabilidades

- **GISELA** (*enGine for Interactive Stories through Events, Links, and Actions*): motor único, sesión, autoridad transaccional, ejecución, observación y acciones.
- **ALBERTO** (*Autonomous Layer for Beings, Environments, Relationships, Traits, and Objects*): modelo interno de mundo; no es otro motor.
- **S.O.F.I.A.** (*Strength, Openness, Fortune, Intelligence, Awareness*): cinco atributos opcionales.
- **TRAITS**: contribuciones cualitativas de rasgos contextuales.
- **DICE**: evaluación matemática independiente; no posee sesión narrativa.
- **MARY**: evaluación de objetivos, progreso y resultados; GISELA confirma las consecuencias.
- **GLAUQUIR**: interfaz textual de referencia, no autoridad de mundo.

Lea la [arquitectura consolidada](../architecture/GISELA_Arquitectura_Consolidada_v1_5.md) y el [índice documental](../README.md) para sus contratos completos. Estos nombres no suponen una capa adicional de coordinación.
