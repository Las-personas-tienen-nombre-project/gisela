# Estado operativo y evidencias

Este directorio conserva el [roadmap vigente](ROADMAP.md), las
[evidencias de ejecución](evidence/README.md) y ocho informes históricos
protegidos por el manifiesto `evidence/revision_documental_2026_11_04/traslados.json`.
Las pruebas verifican su existencia y, cuando corresponde, su integridad.

Los cierres de etapas, auditorías e informes incrementales se resumieron en
[CHANGELOG.md](../../CHANGELOG.md). Los archivos originales retirados se
recuperan mediante el historial Git del repositorio local.

Para ejecutar las verificaciones actuales consulte
[Verificación de GISELA](../guides/VERIFICACION_GISELA.md). Los logs antiguos
no certifican el estado de una revisión posterior.
