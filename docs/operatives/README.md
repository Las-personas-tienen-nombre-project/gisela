## Informes históricos y evidencias

Los archivos `PA001_CONTINUACION_*`, `RESULTADOS_*`, `H*_CIERRE` y las auditorías
fechadas registran el estado observado en cada intervención. Sus cifras y
comandos históricos no describen necesariamente la versión actual. Las
[decisiones de arquitectura](../decisions/) conservan sus estados de aprobación;
las [propuestas de arquitectura](../architecture/) deben contrastarse con los
contratos y el código antes de utilizarlas como instrucciones.

El [archivo de evidencias](evidence/README.md) conserva registros y snapshots
originales. La nueva verificación se guarda por separado; no se reescriben
registros anteriores para reflejar resultados nuevos.
