## PT-01 and PT-02: transactional boundary (H1/H2)

assigns `self._state = draft`. `_publish_pending` similarly projects and validates
before publication; `act` takes the session lock. These are code observations,
not proof that every entry route shares the same commit boundary.

## PT-03: gateway separation (H3)

ADR-020 explicitly makes the gateway optional for external callers. The implementation
of `GiselaSession.act` blocks direct mutation once attached, while unbound sessions
can act locally. Gateway storage persists state and receipt together and fences
uncertain writes. Existing E0 gateway tests passed. **Keep** optional gateway;
no evidence currently justifies removing identity, receipt, or checkpoint logic.
