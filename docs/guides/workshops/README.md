# Talleres de presentación

Ejecute los comandos de estas guías desde la raíz del repositorio, con el entorno
del [inicio rápido](../QUICK_START.md). Las rutas de paquetes escritas en código
se interpretan desde esa raíz.

1. [Regiones y recursos](WORKSHOP_PRESENTACION_V080.md): composición básica,
   fuentes públicas y destinatarios declarados.
2. [Participantes, decisiones y crónica](WORKSHOP_PRESENTACION_V081.md): tres
   disposiciones de la misma batalla.
3. [Tablas, causalidad y plantillas](WORKSHOP_PRESENTACION_V082.md): vistas,
   agrupación de acontecimientos y formatos restringidos.

Para aprender el DSL desde el comienzo, siga el
[taller de autoría de nueve unidades](../../../workshops/autoria_dsl_15/README.md).
Los [informes de entrega](../../operatives/) conservan la evidencia y los límites
de cada incremento. Un ejemplo de presentación no certifica todas las ramas del juego.
