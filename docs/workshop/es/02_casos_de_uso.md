# 2. Casos de uso

GISELA permite crear relatos en los que las decisiones, los acontecimientos y el estado del mundo influyen en lo que ocurre después. No todas las historias necesitan reglas complejas.

## Historias con decisiones

Una persona encuentra un paraguas olvidado. Puede devolverlo, guardarlo o averiguar quién lo perdió. Cada elección conduce a una situación diferente. Este tipo de relato permite comenzar con pocas reglas.

## Historias que recuerdan

Alguien llega a un faro y encuentra una puerta cerrada. Si antes recogió una llave, podrá abrirla; si no lo hizo, deberá buscar otra solución. La historia recuerda los acontecimientos anteriores y los utiliza para decidir qué acciones están disponibles.

## Historias con personajes

Dos personajes presencian el mismo acontecimiento, pero solo uno conoce su causa. Lo que cada uno sabe puede influir en sus acciones y conversaciones. El autor puede declarar conocimientos, relaciones y otras propiedades del mundo.

## Aventuras con objetos y habilidades

Una persona necesita cruzar un puente dañado. Sus capacidades, los objetos disponibles y las decisiones anteriores pueden modificar las opciones que encuentra. El autor establece las reglas y las consecuencias.

## Historias con incertidumbre

Algunas acciones pueden utilizar evaluaciones numéricas con dados y azar controlado. Sus resultados son reproducibles: bajo las mismas condiciones, entradas y semilla, GISELA puede repetir el resultado.

## Objetivos y misiones

Una aventura puede exigir encontrar una pista, conversar con un testigo y llegar a un lugar. GISELA puede evaluar el progreso de un objetivo cuando se cumplen las condiciones declaradas.

## Distintas formas de presentar el relato

GISELA separa el motor de la interfaz. Este repositorio incluye GLAUQUIR, un cliente de texto. La integración con Ren'Py pertenece a un proyecto separado y no es necesaria para usar el motor.

Estos ejemplos ilustran usos posibles, no paquetes ya construidos ni promesas de sistemas especializados. Los talleres enseñarán cada capacidad después de comprobar su soporte.
