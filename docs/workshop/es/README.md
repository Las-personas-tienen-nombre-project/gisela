# Curso de GISELA para autores

Este es el curso práctico de GISELA para autores. Los capítulos introductorios están disponibles; el primer taller práctico ya está disponible. Cada taller tendrá su propio directorio y un ejemplo comprobado.

## Programa

1. [Qué es GISELA y para qué sirve](01_que_es_gisela.md).
2. [Casos de uso](02_casos_de_uso.md).
3. [Instalación y requisitos](03_instalacion.md).
4. [Taller 01. El paraguas olvidado](01_paraguas/README.md). [Taller 02. El faro](02_faro/README.md). Después vendrán personajes, diálogos y decisiones, equipo y objetos, habilidades activas, habilidades pasivas, combate y temas avanzados.
5. Capacidades de GISELA.
6. Referencia del DSL 1.5.

La existencia de un tema en este programa no confirma que tenga soporte especializado en el motor. Cada taller se publicará solo después de contrastar sus funciones con el código, los contratos y los ejemplos.
