# Curso de GISELA para autores

Este curso enseña a escribir historias en GISELA modificando paquetes ejecutables. Si comienzas desde cero, sigue el recorrido en orden. Si buscas una función concreta, consulta directamente el [catálogo](10_capacidades.md) o la [guía de búsqueda del DSL](11_referencia_dsl.md).

## Antes de los talleres

1. [Qué es GISELA y para qué sirve](01_que_es_gisela.md).
2. [Casos de uso](02_casos_de_uso.md).
3. [Instalación y requisitos](03_instalacion.md).

## Talleres prácticos

Cada taller tiene su propia guía y un paquete JSON que puedes ejecutar y modificar. Los talleres posteriores reutilizan conceptos anteriores.

| Taller | Aprenderás a... |
| --- | --- |
| [01. El paraguas olvidado](01_paraguas/README.md) | Crear elecciones y dos finales. |
| [02. El faro](02_faro/README.md) | Recordar hechos y consultar condiciones. |
| [03. Personajes](03_personajes/README.md) | Declarar personajes e instancias. |
| [04. Diálogos y decisiones](04_dialogos_decisiones/README.md) | Escribir intervenciones y elegir respuestas. |
| [05. Objetos y pertenencias](05_objetos_equipo/README.md) | Transferir objetos y consultar propietarios. |
| [06. Habilidades activas](06_habilidades_activas/README.md) | Declarar y utilizar una habilidad. |
| [07. Habilidades pasivas](07_habilidades_pasivas/README.md) | Aplicar rasgos pasivos. |
| [08. Encuentro por turnos](08_combate/README.md) | Resolver resistencia y turnos en el laboratorio `--actuation`. |
| [09. Relaciones y reglas automáticas](09_reglas_relaciones/README.md) | Cambiar relaciones y reaccionar a cambios de estado. |

## Después de los talleres

- [10. Catálogo de capacidades](10_capacidades.md): qué existe, qué está limitado y qué requiere laboratorio.
- [11. Cómo consultar la referencia DSL 1.5](11_referencia_dsl.md): dónde encontrar campos, reglas y errores por tarea.

**Importante:** una función incluida en el catálogo no necesariamente está disponible en el flujo normal de GLAUQUIR. El [taller 08](08_combate/README.md) utiliza expresamente una modalidad de laboratorio.
