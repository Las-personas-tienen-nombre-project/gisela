# Manuales en español

Estos tres capítulos desarrollan el diseño de *El paraguas olvidado*. Se leen
en este orden:

1. [Introducción y herramientas](GISLEA_primera_aventura_narrativa.md): componentes,
   instalación, JSON y validación.
2. [Paquete y conversaciones](GISLEA_primera_aventura_paquete.md): personajes,
   decisiones, hechos, conocimientos, creencias y relaciones.
3. [Sistemas y comprobación](GISLEA_primera_aventura_sistemas.md): atributos,
   rasgos, azar, objetivos y recorridos de prueba.

Los archivos por etapas mencionados en los capítulos no se incluyen en este
repositorio. Sus comandos y resultados describen ejercicios que el lector debe
construir y comprobar. Para comenzar con un archivo completo disponible, consulte
[Crea tu primer paquete](../../guides/CREAR_PAQUETE.md).

La [guía de GLAUQUIR](../../guides/GLAUQUIR.md) reúne las convenciones de consola
y la compatibilidad de guardados. La [guía de verificación](../../guides/VERIFICACION_GISELA.md)
explica qué comprueba cada herramienta del repositorio.
